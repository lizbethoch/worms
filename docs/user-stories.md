Worms - User Stories

1.Account & Authentication
US-001- Create an Account
As a reader, I want to create an account so that I can have my own personal reading library.
US-002- Log In
As a reader, I want to log in to my account so that I can access my personal library.
US-003- Log Out
As a logged-in user, I want to log out so that my account remains secure when I am finished using the application.
US-004- Secure Account
As a user, I want my account information and password to be securely stored so that my personal information is protected. 

2.Personal Library
US-005- Add a Book
As a reader, I want to add a book to my library so that I can keep track of it.
US-006- View My Books
As a reader, I want to view the books in my personal library so that I can see what I am reading and what I plan to read.
US-007- Edit a Book
As a reader, I want to edit a book's information so that I can corrrect or update its details.
US-008- Delete a Book
As a reader, I want to remove a book from my library so that I can keep my library oraganized.
US-009- View Book Details
As a reader, I want to view the details of a book so that I can see its information and my reading progress.
US-010- Protect My Library
As a reader, I want my library to be private to my account so that other users cannot access my books or reading information.

3.Reading Status
US-011- Set Reading Status
As a reader, I want to assign a reading status to a book so that I can organize my library based on what I plan to read, am reading, or have finished.
US-012- Update Reading Status
As a reader, I want to change a book's reading status so that my library accurately reflects my reading activity.
US-013- Filter by Reading Status
As a reader, I want to filter my library by reading status so that I can quickly find books I want to read, am currently reading, or have finished.

4.Reading Progress
US-014- Track Reading Progress
As a reader, I want to record my current page or reading progress so that I can keep track of how far I am in a book.
US-015- View Reading Progress
As a reader, I want to see my reading progress so that I can quickly understand how much of a book I have completed.
US-016- Complete a Book
As a reader, I want to mark a book as completed so that it is recorded as a book I have finished reading.

5.Search & Organization
US-017- Search My Library
As a reader, I want to search my personal library so that I can quickly find a specific book.
US-018- Organize My Library
As a reader, I want my books organized by reading status so that I can easily understand the current state of my  reading list.

6.TBR Randomizer
US-019- View TBR Books
As a reader, I want to view the books on my TBR list so that I can see the books I still want to read.
US-020- Randomly Choose a Book
As a reader, I want Worms to randomly select a book from my TBR list so that Ic an decide what to read next without having to choose myself.
US-021- Use Reading Prompts
As a reader, I want to recieve reading prompts when using the TBR randomizer so that choosing my next book feels more engaging and fun.

7.Ratings
US_022- Rate a Completed Book
As a reader, I want to rate a completed book so that I can record how much I enjoyed it.
US-023- Update a Rating
As a reader, I want to update my rating so that my rating can reflect my opinion if it changes.

8.Reviews
US-024- Write a Review
As a reader, I want to write a review for a completed book so that I can record my thoughts about it.
US-025- Manage My Review
As a reader, I want to edit or delete my review so that I can keep my thoughts up to date or remove them if I no longer want them saved.

Future User Stories

Social Features
-As a reader, I want to add friends so that I can connect with other readers.
-As a reader, I want to see what my friends are reading so that I can discover what they recommend.
-As a reader, I want to see mt friends' ratings and reviews so that I can discover books they enjoyed.
Reading Goals & Statistics
-As a reader, I want to set a yearly reading goal so that I can challenge myself to read more.
-As a reader, I want to view my reading statistics so that I can understand my reading habits.
-As a reader, I want to see a yearly reading summary so that I can look back on my reading accomplishments.
Recommendations
-As a reader, I want personalized book recommendations so that I can discover books I may enjoy.
