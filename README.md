# Worms

A full-stack reading life management application designed for readers to organize their books, track reading progress, and manage their personal to-be-read lists.

## Overview

Worms is a portfolio project focused on building a practical full-stack application from requirements and system design through backend development and API implementation.

The application is designed around the idea that a reader's library is more than a list of books they own. Worms is intended to help readers keep track of what they want to read, what they are currently reading, and what they have finished.

## Current Development

The project is currently under active development.

The backend currently includes:

* Database configuration
* Book data models
* API schemas
* Application entry point
* Books API endpoint

Project requirements, user stories, and architecture documentation are maintained in the `docs/` directory.

## Planned Features

* User accounts and authentication
* Add, edit, and delete books
* Reading status tracking
* Reading progress tracking
* Ratings and reviews
* Search and filtering
* Personalized to-be-read lists
* TBR wheel
